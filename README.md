🧠 Java Console Quiz Application
A feature-rich, console-based Quiz Application built in Java as part of the CodSoft internship tasks. This application presents multiple-choice questions sequentially with a strict per-question time limit, calculates real-time scores, and generates a detailed performance summary at the end.
🚀 Features
  1.Structured Question Bank: Stores quiz questions, multiple-choice options, and verified correct answers using clean object-oriented design.
  2.Per-Question Timer: Implements an automated timer (using java.util.Timer) to limit the response time available for each question.
  3.Sequential Display: Presents questions one at a time for an interactive testing experience.
  4.Timed Answer Submission: Captures user input dynamically within the allowed time window and handles timeouts gracefully
  5.Score Tracking: Dynamically tracks user performance and calculates final scores based on correct submissions.
  6.Comprehensive Result Screen: Displays the final score alongside a detailed summary showing whether each question was answered correctly, incorrectly, or timed out.
